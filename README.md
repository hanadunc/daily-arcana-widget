
# ✦ Daily Arcana — Desktop Companion ✦
*The Fool's Journey*

An occult divination desktop companion widget built with Electron that pulls and displays daily tarot archetypes, astrological alignments, and card interpretations.

Designed as part of a triadic desktop companion suite alongside **Lunar Cycle** and **Wheel of the Year**.

## ✦ Key Features

- **Daily Card Draw:** Pulls daily tarot archetypes with upright and reversed interpretations.
- **Card Telemetry & Astrological Correspondence:** Maps cards to their governing celestial decans, elements, and symbolic keywords.
- **Suite-Matched Design Tokens:**
  - Frameless floating card format with custom draggable header.
  - Antiqued color tokens (`#f2e6d8` parchment cream, `#E3C896` talisman gold).
  - Subtle gold back-glow and star-flanked title flourishes.

## ✦ Tech Stack

- **Runtime:** Electron
- **Target:** Windows Portable executable (`electron-builder`)
- **Frontend:** Vanilla HTML5, CSS custom properties, SVG vectors
- **Typography:** *Cinzel* (card titles & headers), *Lexend* (interpretation copy)
